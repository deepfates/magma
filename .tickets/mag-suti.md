# Ratchet provider, multiplayer, accessibility, and production operations

Build automated representative browser and adapter receipts for the complete requested capabilities, plus production diagnostics, without substituting test activity for implementation.

## Acceptance Criteria

- Adapter contract tests cover parsing, canonicalization, attribution, capability, migration, health failure, and fallback.
- Multi-context browser journeys exercise equal control, convergence, reconnect, reload, actor recovery, source failure, scene composition, artifacts, presence, chat, Block, soundboard, timeline, and voice signaling.
- Real-provider smoke checks are bounded and classify our defect versus provider outage.
- Canvas alternatives, keyboard, reduced motion, muted operation, phone posture, and accessible recovery are covered.
- Production exposes code identity, subsystem health, bounded diagnostic events, and a reproducible deploy/rollback path.
