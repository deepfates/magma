# Add Porch-native image, link, and document artifacts

Extend the tiny tool rail with Image, Link, and lightweight editable Document objects using editor-native mechanics and the durable asset boundary.

## Acceptance Criteria

- Paste/drop image creates a synchronized movable artifact.
- Any URL creates a safe bookmark with title, host, optional safe preview, and Open original.
- Plain or Markdown text can become one editable document card.
- Two people concurrently edit different artifacts, then move, duplicate, delete, reload, import, and export them.
- Existing notes keep their positions and the surface still reads as glass over a world, not a generic whiteboard.
