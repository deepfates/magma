# Apply the Interface Lab instrument grammar across the complete Porch

Give the whole feature set one adaptive composition: world dominant, contextual shelf and objects, semantic commands, ordinary language, retained state across posture changes, and coherent feedback.

## Acceptance Criteria

- Window, glass, instruments, people, Earlier/Now/Next, and configuration fit one room rather than top-level suite tabs.
- Desktop and 390px phone expose the same commands and state with appropriate parallel/condensed/sequential posture.
- Focus, overlays, modals, sheets, keyboard focus, and escape behavior compose without trapping or losing work.
- Motion, sound, and haptics respond to semantic events, honor sensory preferences, and settle.
