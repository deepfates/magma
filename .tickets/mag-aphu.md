# Support honest shared public web surfaces and excursions

Always make a safe link artifact; additionally open allowlisted documented embeds as a shared visual and synchronize only navigation exposed by a supported adapter.

## Acceptance Criteria

- Any URL can become a safe Open original card.
- Embedding is preflighted and blocked CSP/X-Frame-Options falls back cleanly.
- No proxy strips security headers, forwards private cookies, or republishes arbitrary sites.
- Supported adapters synchronize meaningful public navigation.
- A hosted authenticated remote browser remains a separately scoped infrastructure ticket if later explicitly chosen.
